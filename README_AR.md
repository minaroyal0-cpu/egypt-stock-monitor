# Investor Intelligence Free — النسخة المجانية

هذه نسخة أولية قابلة للتشغيل دون اشتراك استضافة أو API مدفوع، باستخدام GitHub Actions + RSS + Telegram Bot API.

## ما الذي تفعله؟
- تفحص مصادر أخبار RSS مجدولة كل 15 دقيقة تقريبًا.
- تلتقط الأخبار المرتبطة بالبورصة المصرية والاقتصاد المصري.
- تمنع تكرار روابط سبق إرسالها عبر ملف `seen.json` داخل المستودع.
- ترسل العنوان والمصدر والتوقيت والرابط إلى Telegram.

## حدود مهمة بصراحة
- هذا ليس بث أسعار لحظيًا، ولا يتتبع أسعار أو أحجام الأسهم في الوقت الحقيقي.
- لا يوجد تحليل ذكاء اصطناعي تلقائي في النسخة المجانية؛ استدعاء نموذج عبر API قد يكلّف مالًا. انسخ الخبر إلى ChatGPT لتحليله.
- GitHub Actions ليس خادمًا دائم التشغيل. المهام المجدولة قد تتأخر أو تُتخطى أحيانًا، ولا توجد ضمانة وصول فوري أو 24/7.
- Google News RSS مصدر تجميعي للعثور على الأخبار، وليس بديلًا عن التحقق من الإفصاح الأصلي في EGX أو بيان الجهة الرسمية.
- لا تستخدم هذا النظام لاتخاذ قرار شراء/بيع دون التحقق من الخبر ومصدره وتوقيته.

## المتطلبات
1. حساب GitHub.
2. حساب Telegram.
3. إنشاء بوت من `@BotFather` والاحتفاظ بـ Bot Token بشكل سري.
4. بدء محادثة مع البوت ثم الحصول على `chat_id` بالطريقة الموضحة أدناه.

## خطوات الإعداد
1. أنشئ مستودع GitHub جديدًا. اجعله **Private** إذا كنت لا تريد نشر ملف سجل الأخبار، أو Public مع الانتباه أن `seen.json` سيكون ظاهرًا للجميع. GitHub Actions المجدول يعمل للمستودع العام أو الخاص ضمن حدود الخطة.
2. ارفع جميع ملفات هذه الحزمة إلى المستودع مع الحفاظ على بنية المجلدات.
3. في Telegram افتح `@BotFather` وأرسل `/newbot` واتبع التعليمات. انسخ التوكن ولا تنشره ولا ترسله في محادثة عامة.
4. افتح رابط البوت الذي أعطاك إياه BotFather واضغط Start.
5. للحصول على `chat_id`، افتح هذا الرابط في متصفحك بعد استبدال `<TOKEN>` بتوكن البوت: `https://api.telegram.org/bot<TOKEN>/getUpdates`. ابحث عن `message` ثم `chat` ثم `id`. لا تشارك الرابط أو مخرجاته؛ يحتوي الرابط على سرّ البوت.
6. في GitHub: `Settings → Secrets and variables → Actions → New repository secret`، أضف:
   - `TELEGRAM_BOT_TOKEN` = توكن البوت.
   - `TELEGRAM_CHAT_ID` = رقم chat id.
7. من `Actions` فعّل workflows إن طُلب ذلك، ثم شغّل `Investor Intelligence RSS Monitor` يدويًا عبر `Run workflow`.
8. راجع سجلات التشغيل في Actions وتأكد من وصول رسالة إلى Telegram.

## التشغيل والتخصيص
- الجدولة في `.github/workflows/monitor.yml` مضبوطة كل 15 دقيقة (`*/15 * * * *`) بتوقيت UTC. هذا لا يعني تنفيذًا دقيقًا كل 15 دقيقة؛ GitHub قد يؤخر التشغيل.
- عدّل كلمات البحث ومصادر RSS في `src/monitor.py`.
- راجع `seen.json` بعد أول تشغيل.
- لا تضف التوكن إلى ملفات الكود أو الرسائل أو سجل Git.

## استكشاف الأخطاء
- لا توجد رسالة: تأكد أنك ضغطت Start مع البوت، وأن `chat_id` صحيح، وأن السرّين مكتوبان بشكل صحيح.
- لا توجد أخبار: قد تكون نتائج RSS فارغة أو متأخرة؛ جرّب تشغيل workflow يدويًا.
- تكرار/فقد أخبار: GitHub Actions قد يتأخر، وقد تحدث حالات فشل. هذه نسخة تجريبية وليست نظام تداول حرجًا.
